# Surcharge — Accueil (« Ce qui rapporte »)
- Ouverture ≤ 3 s : rideau, filet d'or, gerbe, montée des tours ; jamais bloquante (le contenu est lisible pendant l'animation).
- Un seul appel à l'action principal par écran (« Entrer dans l'espace métiers ») ; le parcours « Je suis… » oriente sans concurrencer.
- Cité 3D décorative pour l'accessibilité : les chiffres sont portés par le texte (titre, classement, tableaux).
